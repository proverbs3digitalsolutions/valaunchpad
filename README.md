# VA Launchpad

A web app that trains Filipino social media managers in a 12-week program. Learners work through daily lessons, submit drafts for AI and rubric critique, and track progress on client pages. Owners see their team's progress.

## Where things are

- `docs/design/`: design tokens and the visual rules
- `docs/data-model.md`: database tables and rules to test
- `.claude/skills/`: the quality gates, the Taglish coach rules, the security checklist, and the glass design rules

## Before merging anything

Run the quality gates in `.claude/skills/quality-gates/SKILL.md`. The owner approves after every gate passes.
